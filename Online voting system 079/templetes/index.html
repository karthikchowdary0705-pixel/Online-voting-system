Cloud-Based Online Voting System

Welcome to CloudVote, a simple web-based voting platform developed using Python Flask and SQLite. Register, login and cast your vote online.

☁️ Cloud Based

The application can be accessed through a web browser and can be deployed on a cloud server.

🔐 User Login

Users can create an account and securely login before accessing the voting page.

🗳️ One Vote

Each registered user is allowed to cast one vote in the demonstration election.
